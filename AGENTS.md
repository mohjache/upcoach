## Layout
- Spacing between sub headers and text should be equal to 8px or 0.5rem (tailwind padding this is p-2)
- Padding on cards or between hero titles and actions should be 16px or 1rem (tailwind padding this is p-4)
- Column gaps between related elements should be 24 px or 1.5 rem (tailwind padding this is p-6)
- Gaps between unrelated components should be 32px or 2rem (tailwind padding this is p-8)
- Outer layer gutters should be 32px or 2rem (tailwind padding this is p-8)

## Typography
- On most text prefer text to be left-aligned and vertically aligned to the baseline
- The exceptions are for components:
    1. Hero
- Ensure use of a sans-serif font
- h1 titles should be in tailwind text-4xl bold text-foreground
- h2 text-3xl bold text-foreground
- h3 text-2xl bold text-foreground
- h4 text-xl bold text-foreground
